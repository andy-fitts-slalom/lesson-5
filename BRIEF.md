# My Links - Project Brief
A personal link-in-bio page. One page, clean design, mobile-first. I want to send people here from my social profiles.

## Tech
- Pure HTML, CSS, and JavaScript - no frameworks, no build tool-
- Single index. html file (CSS and JS can be separate files)
- Deploys to Vercel as a static site

## Design
- Centered card layout, max-width 480px
- My name as a heading, short bio underneath
- Profile photo placeholder (circle, 120px)
- Dark mode by default with a light/dark toggle
- Smooth hover animations on the link buttons
- Google Font: Inter
- I want subtle animation to occur in the background pattern that is responsive to mouse movement
- base the color scheme off of my portfolio site
